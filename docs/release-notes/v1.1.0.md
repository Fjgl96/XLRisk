## XLRisk 1.1.0

Primera versión de este fork. Es compatible con los libros hechos con el XLRisk original.

### Descargas
- **XLRisk.xlam**: el complemento. Después de descargarlo: clic derecho > Propiedades > **Desbloquear**, cópialo a `%APPDATA%\Microsoft\AddIns` y actívalo en Desarrollador > Complementos de Excel > Examinar.
- **XLRisk_Manual_ES.xlsx**: manual en español con un modelo de ejemplo listo para simular.
- **XLRisk.xlam.sha256**: checksum para verificar el archivo (`Get-FileHash XLRisk.xlam`).

### Qué cambia
- Generador de números aleatorios MRG32k3a en lugar de `Rnd()` de VBA: mismos resultados en Excel de 32 bits, 64 bits y Mac.
- Una semilla fija ahora reproduce toda la simulación. En el original, la primera corrida de cada sesión daba otros números.
- Shuffle del Latin Hypercube sin sesgo.
- 20 autopruebas contra resultados exactos (Alt+F8 > `XLRisk.xlam!XLRiskSelfTests`). Este build pasó 20 de 20.
- Función `=XLRiskVersion()`.

Como cambió el generador, un libro con semilla fija da números distintos a los de la versión original. Para reproducirlos, agrega en la hoja XLRisk una celda con nombre `LegacyRnd` = VERDADERO.

El complemento no tiene firma digital. Detalle completo en el [CHANGELOG](https://github.com/Fjgl96/XLRisk/blob/master/CHANGELOG.md).
